# 1st Web Page

## Run locally on Replit

This is a static HTML/CSS site with no package installation or backend required.

The Replit workflow serves the project from the repository root at:

```text
http://0.0.0.0:5000
```

To run it manually:

```bash
python3 -m http.server 5000 --bind 0.0.0.0
```

Open `index.html` through the Replit preview.
